Layer 2 — Self-Healing Loop (autonomous)

Steps 1–4 execute without human intervention. The Sentinel monitors live telemetry, Pathfinder traces the causal graph, Synthesiser generates contract-compliant patches via LLM, and Validator tests each candidate in a fully isolated shadow environment with 90-day data replay.

Human gate + Deployment

Step 5 uses intelligent routing: known low-severity issues are auto-approved and assigned directly to the appropriate agent. Only high-impact or unknown patterns require human review. Upon approval, Step 6 deploys via ArgoCD GitOps with automatic rollback if health metrics breach thresholds within 90 seconds.

Steps 1–4 are fully autonomous (Layer 2 Self-Healing Loop) · Step 5 is the only human step · Step 6 closes the feedback loop back to Sentinel

Process — Sentinel

Sentinel
Fault Detection Agent
Flink · Kafka · SPC · Pydantic

GitOpsArgoCDDeclarative K8s sync, auto-rollback, drift detection
InfrastructureTerraformReproducible infrastructure, state management, multi-cloud

Audit StorePostgreSQLACID compliance, append-only audit patterns, mature ecosystem

Technology selection prioritised three criteria: (1) production readiness — all components are battle-tested in industry; (2) interoperability — standard protocols and open APIs between layers; and (3) observability — every component emits structured telemetry for the self-healing loop.

Research contribution: NEXIS demonstrates that a dual-layer multi-agent architecture — with role-specialised collaborative agents (Layer 1) and an autonomous self-healing loop (Layer 2) — can achieve reliable end-to-end software engineering automation. The primary research challenge is Step 3 (Synthesiser): generating a correct, safe fix for a software failure the system has never seen before, using only failure evidence and the system's own design contracts.
